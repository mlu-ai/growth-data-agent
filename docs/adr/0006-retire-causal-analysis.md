# Retire causal analysis

The agent no longer produces Causal Estimates, treatment effects, or root
causes; the causal-analysis workflow of ADR-0005 is retired in favor of
governed Candidate Causal Factor hypotheses and conditional Opportunity
Estimates. A causal-phrased request returns a non-causal limitation redirecting
the Agent User to the metric's Driver Decomposition and evidence-backed
Hypotheses.

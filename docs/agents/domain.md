# Domain Docs

Before domain work, read root `CONTEXT.md` and the relevant ADRs in `docs/adr/`
when they exist. If they are absent, proceed without creating them.

This is a single-context repository:

- `CONTEXT.md` holds shared domain vocabulary.
- `docs/adr/` holds architectural decisions.

Use terms from `CONTEXT.md` in plans, issues, and code. Surface any conflict
with an existing ADR explicitly.

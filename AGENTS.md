## Agent skills

### Issue tracker

Use GitHub Issues for repository work. Read [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md) before creating, triaging, or updating an issue.

### Triage labels

Use the canonical label mapping in [docs/agents/triage-labels.md](docs/agents/triage-labels.md) when triaging issues.

### Domain docs

For domain work, read the relevant root `CONTEXT.md` and ADRs in `docs/adr/` when they exist. Layout and consumer rules live in [docs/agents/domain.md](docs/agents/domain.md).
